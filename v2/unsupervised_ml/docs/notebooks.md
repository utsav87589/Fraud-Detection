### ------------ Folder name : notebooks --------------------

- here is all the information about the data folder, the way folder is structured and the stuff inside each one of them.

- in the notebook folder, we have all the core logic written in combination with the src file functions to form the clusters/finding out the anomalies in the dataset.

- we have 3 notebook files : 

1. basic_processing.ipynb : we did the basic processing like, loading the data, separating the target feature from the dataset to make it prepare for the clustering

2. anomaly.ipynb : did the anomaly detection using DB scan, LOF (local outlier factor) and Isolation forest.

3. clustering.ipynb : did the clustering on the data using the Kmeans, DB Scan and HM clustering.
